# Reporting a correction or asking a technical question

Use the repository closest to the issue: SDK for validation, Labs for an exercise, Docs for guidance, Security Model for non-sensitive review criteria, or this landing repository for cross-repository scope.

Include the page or file, repository commit/version, exact disputed behavior, expected result and a primary source with its checked date when applicable. Reproduce code problems with invented data and the documented command. State what remains uncertain.

Do not post credentials, customer records, private topology or sensitive findings. For security concerns, contact [security@mkdl.jp](mailto:security@mkdl.jp) and request a suitable private channel before sharing details. See [disclosure policy](https://github.com/Mysthrala-Kurogane-Defense-Labs/kurogane-security-model/blob/main/disclosure-policy.md).

A correction is complete when the claim or behavior is changed, relevant checks pass and the result is reviewed. Opening an issue or PR alone is not closure.
