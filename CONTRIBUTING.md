# Contributing

Contributions are welcome when they improve the public technical ecosystem around Kurogane Hub without crossing confidentiality or safety boundaries.

Accepted contribution areas include documentation clarity, public architecture wording, issue templates, glossary improvements, synthetic lab ideas, event-contract feedback, and integration questions.

Do not contribute production Kurogane Hub source code, detection logic, customer deployment logic, internal orchestration details, credentials, internal endpoints, IP addresses, or real plant data.
